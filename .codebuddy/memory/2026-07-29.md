## 修复“搜索后显示空白”bug（升至 v1.3.2）

根因：克隆京东原生卡片时仅清除了 `hideNativeProducts()` 写入的**内联** `display:none`，但京东页面 CSS 通过**类名**（lazy/hidden 等变体）隐藏卡片，`card.style.display=''` 还原为 class 级 `display:none` → 结果面板空白。

修复（`src/ui/products.js`）：先把 `grid` 挂载到面板，再逐卡片用 `getComputedStyle` 检测 `card`/`img`/`img.parentElement` 实际 `display==='none'` 时强制 `'block'` 兜底。`src/ui/results.js` 为空状态浮层 `.jds-empty-overlay` 补显式背景/边框/圆角/阴影（Light DOM 不继承 Shadow 组件样式）。

版本号统一升至 1.3.2（23 个 JS 文件头 + manifest/package/metadata + prototype 徽标 + README 打包名）；CHANGELOG 与 openspec/tasks 补 v1.3.2 条目。验证：`search_bug_test.js` 真实 DOM 模拟 9 项断言全过（面板创建、可见、2 卡片、名称/链接填充、无匹配空状态）。临时测试文件已删除。

## 继续修复“搜索结果不显示”bug（升至 v1.3.3）

v1.3.2 的 `getComputedStyle` 兜底仍不足以覆盖真实页面：**京东虚拟列表/懒加载会把克隆卡片的内容高度压为 0（display 非 none）**，导致结果面板整片空白但 `display` 正常。原克隆方案还继承京东列表容器的 flex/`!important` 布局，脆弱且依赖京东真实 DOM。

修复（`src/ui/products.js`）：
- `renderProducts` 改为**统一使用扩展自带网格容器**（内联 `display:grid` 等，避免继承京东列表布局干扰）。
- 对每张克隆京东原生卡片做**实测可见性校验**：挂载后若 `getComputedStyle(card).display==='none'` 或 `getBoundingClientRect().height===0`（零高度/虚拟列表），自动 `replaceChild` 为扩展自带内联样式卡片（`_buildOwnCard`：a 标签卡片，图片+标题+价格，京东红主色，主图失败回退 📦，新窗口打开，悬停阴影）。
- 无原生模板时也走 `_buildOwnCard`。
- 删除原 `_renderFallbackCards`，由 `_buildOwnCard` 承担兜底；`_fillNativeCard` 保留用于克隆卡片填充。

验证：临时 `verify_render.js`（最小 DOM 桩 + results.js）四路径全过——无模板→2 张自带卡片、有模板可见→2 张克隆卡片、有模板零高度→回退自带卡片(a)、空商品→空状态。临时脚本已删除。
版本统一升至 1.3.3（26 个 JS/JSON + prototype 双徽标 + README/README_EN 打包名）；CHANGELOG/openspec/tasks/spec 同步。
