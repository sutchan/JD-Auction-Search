- 需求：搜索要覆盖 auction-list/ 的所有分页商品，而非仅当前 DOM 商品。
- 根因：原 DOM 隐藏式过滤只能作用于当前页节点，跨页匹配项不在 DOM 中无法呈现 → 必须有独立结果渲染。
- 改动：
  - api.js 新增 `loadAllProducts(params, maxPages=30)`：顺序翻页（pageSize=50，tab=all），按商品 id 去重，整页重复或不足一页即停（防重复/防无限）。
  - dom.js 新增 `hideNativeProducts()/showNativeProducts()`（基于 `_getProductContainers` 设 display none/''）。
  - ui.js 新增独立结果面板宿主 `#jds-results-host`（Shadow DOM 挂 body，fixed 定位在嵌入工具栏下方，top 由 `#jds-search-wrapper` 的 getBoundingClientRect().bottom 实时计算，监听 scroll/resize 跟随）；`showResults/hideResults`；空状态改挂 resultsRoot；destroy 清理 resultsHost。
  - content.js：state 加 `searchMode`；`_autoLoadProducts` 改用 `loadAllProducts`（聚合全部分页，不再单页）；`_applyFilterAndUpdate` 改为「有筛选→搜索模式：渲染结果面板+隐藏原生列表；无筛选→浏览模式：恢复原生+隐藏面板」；观察器回调加 searchMode 守卫；`_handleToggle` 停用分支恢复原生+隐藏面板。
- 行为：搜索/分类激活时展示跨页结果面板；清空后恢复京东原生列表与实时 DOM 过滤；API 失败时降级从当前 DOM 提取。
- 版本升 1.2.5，CHANGELOG/spec/tasks 新增条目。node --check 全过。
- 注意：结果面板 fixed 定位依赖嵌入工具栏在视口顶部；页头非 sticky 时滚动会带偏，已用 Math.max(0,...) 兜底。

## v1.2.10 搜索结果视觉一致（克隆京东原生卡片）
- 需求：搜索结果显示的商品卡片要和 `auction-list` 原始页面卡片显示效果一致。
- 根因/关键决策：**克隆的京东卡片必须放在 light DOM（不能放 Shadow DOM）**，否则京东全局 CSS 不穿透 Shadow，卡片会“裸奔”。因此把 `#jds-results-host` 从 Shadow 改为真实 DOM（仅外壳样式注入 `document.head` 的 `#jds-results-style`）。
- ui.js `_initResultsHost`：host 不再 `attachShadow`，改为 light DOM；面板 `.jds-results-panel` 绝对定位覆盖内容区，`background:#fff`。
- ui.js `renderProducts`：优先 `JDSDom.getFirstProductCard()` 取原生模板；克隆其 `parentElement`（grid 容器，`cloneNode(false)` 保留 grid 布局 class，去掉 id），逐商品 `cloneNode(true)` 后 `_fillNativeCard` 填主图/标题/价格/链接，append 到克隆容器；无模板时回退 `_renderFallbackCards`（内联样式，独立于 Shadow CSS）。
- ui.js `_fillNativeCard`：强制 `opacity:1/visibility:visible` 规避京东懒加载/入场动画 opacity:0；填 `img.src`（去 srcset，onerror 隐藏）、`[class*=name|title|h3|h4]` 标题、`[class*=price]` 价格（`¥`+formatPrice）、`closest('a')||a` 链接（getProductUrl，target=_blank）；清理 `[class*=countdown|remain|time|timer]` 残留动态信息；移除克隆卡片 id。
- utils.js 新增 `getProductUrl`（url/link/detailUrl/href... 白名单，无则回退 `https://paimai.jd.com/{id}.html`）；dom.js 新增 `getFirstProductCard()`。
- 注意：跨页聚合项在原生 DOM 无对应真实卡片，用模板克隆+覆盖主字段，次要角标沿用模板（可接受，用户只要求“显示效果一致”）。
- 版本升 1.2.10：同前清单。验证：ui.js/dom.js/utils.js/content.js `node --check` 全过；新方法接线正确。
