## 多页面搜索 + 升 v1.2.5
- 需求：搜索要覆盖 auction-list/ 的所有分页商品，而非仅当前 DOM 商品。
- 根因：原 DOM 隐藏式过滤只能作用于当前页节点，跨页匹配项不在 DOM 中无法呈现 → 必须有独立结果渲染。
- 改动：
  - api.js 新增 `loadAllProducts(params, maxPages=30)`：顺序翻页（pageSize=50，tab=all），按商品 id 去重，整页重复或不足一页即停（防重复/防无限）。
  - dom.js 新增 `hideNativeProducts()/showNativeProducts()`（基于 `_getProductContainers` 设 display none/''）。
  - ui.js 新增独立结果面板宿主 `#jds-results-host`（Shadow DOM 挂 body，fixed 定位在嵌入工具栏下方，top 由 `#jds-search-wrapper` 的 getBoundingClientRect().bottom 实时计算，监听 scroll/resize 跟随）；`showResults/hideResults`；空状态改挂 resultsRoot；destroy 清理 resultsHost。
  - content.js：state 加 `searchMode`；`_autoLoadProducts` 改用 `loadAllProducts`（聚合全部分页，不再单页）；`_applyFilterAndUpdate` 改为「有筛选→搜索模式：渲染结果面板+隐藏原生列表；无筛选→浏览模式：恢复原生+隐藏面板」；观察器回调加 searchMode 守卫；`_handleToggle` 停用分支恢复原生+隐藏面板。
- 行为：搜索/分类激活时展示跨页结果面板；清空后恢复京东原生列表与实时 DOM 过滤；API 失败时降级从当前 DOM 提取。
- 版本升 1.2.5，CHANGELOG/spec/tasks 新增条目。node --check 全过。
- 注意：结果面板 fixed 定位依赖嵌入工具栏在视口顶部；页头非 sticky 时滚动会带偏，已用 Math.max(0,...) 兜底。
