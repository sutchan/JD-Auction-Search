## 多页面搜索 + 升 v1.2.5
- 需求：搜索要覆盖 auction-list/ 的所有分页商品，而非仅当前 DOM 商品。
- 根因：原 DOM 隐藏式过滤只能作用于当前页节点，跨页匹配项不在 DOM 中无法呈现 → 必须有独立结果渲染。
- 改动：
  - api.js 新增 `loadAllProducts(params, maxPages=30)`：顺序翻页（pageSize=50，tab=all），按商品 id 去重，整页重复或不足一页即停（防重复/防无限）。
  - dom.js 新增 `hideNativeProducts()/showNativeProducts()`（基于 `_getProductContainers` 设 display none/''）。
  - ui.js 新增独立结果面板宿主 `#jds-results-host`（Shadow DOM 挂 body，fixed 定位在嵌入工具栏下方，top 由 `#jds-search-wrapper` 的 getBoundingClientRect().bottom 实时计算，监听 scroll/resize 跟随）；`showResults/hideResults`；空状态改挂 resultsRoot；destroy 清理 resultsHost。
  - content.js：state 加 `searchMode`；`_autoLoadProducts` 改用 `loadAllProducts`（聚合全部分页，不再单页）；`_applyFilterAndUpdate` 改为「有筛选→搜索模式：渲染结果面板+隐藏原生列表；无筛选→浏览模式：恢复原生+隐藏面板」；观察器回调加 searchMode 守卫；`_handleToggle` 停用分支恢复原生+隐藏面板。
- 行为：搜索/分类激活时展示跨页结果面板；清空后恢复京东原生列表与实时 DOM 过滤；API 失败时降级从当前 DOM 提取。
- 版本升 1.2.5，CHANGELOG/spec/tasks 新增条目。node --check 全过。
- 注意：结果面板 fixed 定位依赖嵌入工具栏在视口顶部；页头非 sticky 时滚动会带偏，已用 Math.max(0,...) 兜底。

## UI 简化 + 升 v1.2.6
- 需求：简化扩展 UI —— 去除「夺宝搜索」标题（Logo）、搜索结果数量统计（Count）、「已启用本地」开关（Toggle）。
- 决策：项目 manifest 无 popup/options 页面，「启用/禁用」开关的唯一入口就是页面内 Toggle 按钮，移除按钮后该特性即成无 UI 的死代码，故**整体移除 enable/disable 机制**（而非仅删按钮），扩展默认常驻启用。
- 改动：
  - ui.js：`_getUIMarkup` 仅保留 `jds-search`+`jds-tabs`；删除 `.jds-toolbar.is-disabled`、`.jds-logo*`、`.jds-count`、`.jds-toggle*` 全部 CSS 及移动端媒体查询对应行；移除 `updateResultCount/updateToggleBtn/setToolbarEnabled` 方法（R5 前期已删）。
  - content.js：state 删 `isEnabled`；`_applyFilterAndUpdate` 删 `updateResultCount` 调用与 `!isEnabled` 分支；删 `_handleToggle` 方法与 `onToggle` 回调；`_autoLoadProducts` 删 `updateToggleBtn`/`isEnabled` 赋值；`_setupMessageListener` 删 `TOGGLE_ENABLED` 分支。
  - dom.js：`observeDOM` 守卫 `shouldUpdate && state.isEnabled` → `shouldUpdate`；`updateProductDisplay` 删 `!state.isEnabled` 早退块。
  - api.js：`_interceptXHR` 守卫 `state.isEnabled && _isAuctionUrl` → `_isAuctionUrl`。
  - background.js：删 `state.isEnabled` 字段及 `GET_STATE`/`TOGGLE_ENABLED` case；安装日志版本更新。
- 版本升 1.2.6：manifest/metadata/package JSON + 全部 src/*.js 头 + styles.css 头 + background.js 日志 + README(_EN) zip 名 + prototype 两处徽标 + CHANGELOG/spec/tasks 新增条目；spec 功能清单「一键启停」标记移除。
- 验证：6 个 JS 文件 `node --check` 全过；全仓无 `updateResultCount/updateToggleBtn/setToolbarEnabled/_handleToggle/onToggle/isEnabled/GET_STATE/TOGGLE_ENABLED` 残留引用。
