04 — Interaction Standards

一致的 交互准则

反馈、加载、错误、空状态——四种核心交互模式统一规范，确保用户在任何场景下都获得可预期的体验。

/ Feedback
操作反馈
所有用户操作必须即时反馈：Toast 通知、按钮态变化、计数更新。反馈延迟不超过 100ms。
/ Loading
加载状态
数据加载超过 300ms 时显示 Skeleton 占位，避免空白闪烁。商品卡片用 shimmer 动画。
/ Error
错误状态
API 失败时降级为 DOM 提取，并以 destructive Toast 提示。不阻塞核心功能。
API 加载失败
已切换至页面内容提取模式
/ Empty
空状态
无匹配结果时展示 EmptyState，提供图标、标题、描述与建议操作，引导用户调整筛选。
