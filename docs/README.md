# 截图与素材

本目录存放用于 GitHub 仓库展示的素材。

## screenshots/

在 `docs/screenshots/` 放置以下扩展运行截图（PNG，建议 1280×720 或 800×600）：

| 文件名 | 内容 | README 引用 |
|--------|------|-------------|
| `search.png` | 搜索框输入关键词、结果面板实时过滤 | 效果预览·搜索过滤 |
| `empty.png` | 无匹配商品时的空状态提示 | 效果预览·空状态 |
| `history.png` | 聚焦搜索框显示的历史记录下拉 | 效果预览·搜索历史 |

> 截图请勿包含个人隐私或登录信息。

## social-preview.png

仓库头部社交预览图（1280×640，GitHub 推荐尺寸）。在仓库
**Settings → General → Social preview** 中上传，作为仓库分享到社交平台时的封面。
