核心功能

实时搜索

在已加载列表中即时过滤商品，关键词高亮，120ms 防抖，无需重新请求。

跨页聚合

将夺宝岛分散在多个分页的商品聚合到单一结果面板，统一排序、统一检索。

分类筛选

覆盖手机数码、电脑办公、家电、服饰、奢侈品、乐器、文玩 7 大类，一键收窄结果。

搜索历史

记忆最近 10 条关键词，支持单条删除与一键清空，下次检索更顺手。

本地安装

三步加载到浏览器

构建产物

运行 npm run build，产物输出至 releases/jd-auction-search-vX.Y.Z.zip，解压得到扩展目录。

开启开发者模式

浏览器地址栏访问 chrome://extensions，右上角开启「开发者模式」。

加载解压的扩展

点击「加载已解压的扩展程序」，选择解压后的目录即可启用。

开始使用

打开京东夺宝岛列表页，顶部即出现搜索工具栏，开始检索。

常见问题

FAQ

支持哪些浏览器？

基于 Manifest V3，支持 Chrome 及兼容 Chromium 内核的浏览器（Edge、Brave 等）。Firefox 需做少量适配，暂未官方验证。

会收集我的数据吗？

不会。扩展仅在本地处理夺宝岛页面内容，搜索历史保存在浏览器本地，不上传任何个人信息。隐私数据默认关闭。

官方接口失效会怎样？

扩展已内置兜底逻辑：当官方接口不可用或变更时，自动降级为解析页面 DOM 提取商品信息，并通过轻提示告知，核心搜索体验不中断。

为什么是零依赖？

为控制注入脚本体积（约 26KB）与启动性能，所有逻辑以原生 JS + CSS 实现，并通过 Shadow DOM 隔离样式，避免引入第三方库带来的开销与冲突。
